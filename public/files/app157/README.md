# مختبر الجغرافيا الذكي

**Smart Geography Teaching Lab — الإصدار 1.0**

تطبيق ويب عربي RTL للتدريب على تدريس الجغرافيا وبناء المشروعات الرقمية. يعمل بملفات HTML وCSS وJavaScript ثابتة، دون قاعدة بيانات أو حسابات أو خادم خلفي. جميع المكتبات والخطوط مرفقة محليًا.

## التشغيل السريع

1. فك ضغط الحزمة كاملة في مجلد واحد.
2. افتح `index.html` في إصدار حديث من Chrome أو Edge أو Firefox. لا تفتح الصفحة من داخل معاينة ملف ZIP؛ فك الضغط أولًا.
3. اختر نمط المعلم أو الطالب.
4. احفظ الجلسة باستخدام «حفظ الجلسة» قبل التحديث أو إغلاق الصفحة. الحفظ ينزّل ملف JSON؛ لا توجد ذاكرة دائمة تلقائية.
5. لاستكمال العمل افتح أيقونة المجلد في أعلى الصفحة، واختر JSON. يُفحص الملف ثم يظهر ملخص قبل استبدال الجلسة الحالية.

لا يحتاج الاستخدام إلى تثبيت Node.js أو Python أو PHP أو إلى اتصال بالإنترنت. الحزمة لا تستدعي خدمات ذكاء اصطناعي أو مفاتيح API. إن فرض متصفحك سياسة تمنع الموارد المحلية، ارفع المجلد كاملًا إلى استضافة ملفات ثابتة داخل منصتك.

## ما يتضمنه التطبيق

- لوحة رئيسية عربية متجاوبة، مع شريط تنقل جانبي ونمطي معلم وطالب.
- ثلاثة موديولات بالترتيب المحدد: التخطيط (3 مهارات)، التنفيذ (9)، التقويم (1).
- لكل مهارة: موقف جغرافي، تشخيص، نشاط تفاعلي، تحدٍّ في موقف جديد، ومهمة تطبيقية مكتوبة بثلاثة بنود للمراجعة.
- أنشطة اختيار قرارات، وترتيب خطوات بأزرار قابلة للاستخدام بلوحة المفاتيح، وتصنيف المحتوى والأسئلة.
- مرشد مشترك يقدم ثلاثة مستويات للدعم وتلميحات متدرجة وأمثلة وتغذية راجعة خاصة بالبدائل.
- لوحة أداء من بيانات الجلسة، مع محاولات كل مهارة ومساعداتها وأدلة الممارسة الرقمية.
- خطة تدريس قابلة للتحرير والتصدير، مع إدراج مسودات التدريب في الحقول الفارغة.
- مشروع بسبع مراحل: السؤال، الخطة، المعلومات والمصادر، التحليل، الإنتاج، العرض، التقويم.
- مصادر موثقة بمسار بحث ومبررات ملاءمة وفحوص يقرها المستخدم، ومعلومات وبيانات مرتبطة بمعرف المصدر.
- رسم بياني من قيم المستخدم، وتصنيف المعلومات، وتفسير العلاقات وحدود البيانات.
- محرر منتج يدعم الفقرات، بطاقات النتائج، الصور المحلية ووصفها ومصدرها، تغيير الترتيب، قالبين، ولونًا مخصصًا، مع جدول ورسم ومعاينة مباشرة.
- تعليمات المعلم وأوصاف الأداء المستهدف محفوظة وتظهر للطالب. هذا اختلاف في واجهة الاستخدام، وليس نظام صلاحيات أو حسابات.
- تقويم يدوي من خمسة معايير وأربعة مستويات موصوفة، مع دليل لكل حكم وتحسينات مقترحة.
- تنزيل المشروع الكامل أو بطاقة التقويم أو تقرير الأداء أو خطة التدريس PDF، وتنزيل ملصق PNG بعرض 2000 بكسل، والطباعة A4.
- حفظ واستيراد الجلسة كاملة، بما فيها المشروع والصور ونتائج التدريب وخطة التدريس.

## رحلة الاستخدام

### تدريب المعلم

افتح «التدريب الأكاديمي»، ثم اختر المهارة. التشخيص يُسجّل من المحاولة الأولى ويمكن متابعة التطبيق حتى إذا لم تكن الإجابة مناسبة. في التطبيق والتحدي المستقل تحتاج قرارًا صحيحًا للانتقال. يمكنك طلب تلميح أو مثال. بعد التحدي اكتب استجابتك النهائية، وأكمل دليل الممارسة الرقمية عند وجوده، ثم راجع البنود واعتمد المراجعة الذاتية.

يمكنك حفظ المسودة داخل الجلسة ومتابعتها؛ هذا لا يغني عن تنزيل JSON. تعديل الاستجابة بعد اعتمادها يعيدها لحالة تحتاج مراجعة.

### المشروع

يمكن زيارة أي مرحلة لتحريرها، بينما يعتمد زر «مراجعة المرحلة والمتابعة» اكتمال عناصر المرحلة فقط. عند التعديل تُلغى اعتمادات المراحل المتأثرة لاحقًا مع الاحتفاظ بمحتواها. لا تعني زيارة المرحلة أو ملء الحقول إتقانًا أو درجة جودة.

في مرحلة المعلومات أضف مصدرًا ومعلومة مرتبطة به. وفي مرحلة التحليل أضف صفين من البيانات على الأقل، ووحدة القياس ومصدر كل صف، ثم صنّف المعلومات واكتب التفسير والاستنتاج. البيانات لا تُجلب تلقائيًا، ولا يُتحقق علميًا من صحتها داخل الأداة.

في مرحلة الإنتاج أضف نصوصًا وصورًا ونتائج. يظهر جدول البيانات والرسم تلقائيًا في المنتج. بعد المراجعة فعّل إقرار فحص المعاينة. مرحلة العرض تحتوي على التصدير، ثم مرحلة التقويم تسجل الأحكام البشرية وأدلتها.

يمكن تصدير مسودة قبل اكتمال المشروع؛ يذكر الغلاف أنها نسخة عمل.

## معنى المؤشرات

- **صحة القرارات:** نسبة الإجابات الصحيحة من أول محاولة في كل مهمة موضوعية جُرّبت. إعادة المحاولة لا تستبدل نتيجة المحاولة الأولى.
- **الاستقلالية:** نسبة القرارات الصحيحة في أول محاولة دون تلميح سابق إلى جميع المهام الموضوعية التي جُرّبت. هي وصف لسلوك داخل المحاكاة، وليست سمة ثابتة للمعلم.
- **تقدم المهارة:** 25% لكل من إتمام التشخيص، نجاح التطبيق، نجاح التحدي، وإتمام المهمة النصية ومراجعتها. نسبة التقدم مؤشر إنجاز، وليست درجة جودة.
- **تقدم الموديول:** نسبة المهارات ذات المهام النهائية المعتمدة بالمراجعة الذاتية.
- **المجالات الرقمية:** عدد المجالات التي لديها دليل ممارسة محدد من مهمة مكتوبة مراجعة أو من مرحلة مشروع معتمدة. هذا ليس اختبار إتقان رقمي.
- **بطاقة المشروع:** درجات يختارها المستخدم أو المعلم يدويًا بمستويات 1–4 مع دليل. الحقل غير المقيّم يظل «لم يُقيّم»، وليس صفرًا ضمنيًا.

التقارير تذكر صراحة أن النتائج تدريبية داخل المحاكاة، وليست قياسًا علميًا معتمدًا لفاعلية البرنامج البحثي. لا يفحص النظام جودة النص بكلمات مفتاحية، ولا يصحح المصادر علميًا أو يثبت أن الروابط صحيحة. حدود طول النص هي فحوص اكتمال فقط.

## قواعد محرك الدعم

الاسم البرمجي `Lab.SmartSupportEngine`، في `assets/js/smart-support.js`.

1. يبدأ الدعم متوسطًا.
2. القرار غير المناسب يرفع مستوى الدعم خطوة حتى مرتفع.
3. أول خطأ يستدعي تلميحًا عامًا؛ الخطأ الثاني تلميحًا محددًا؛ الثالث مثالًا توضيحيًا.
4. القرار الصحيح يخفض الدعم خطوة حتى منخفض.
5. ينجح المستخدم في التطبيق ثم ينتقل إلى سؤال جديد في سياق قريب قبل المهمة المفتوحة.
6. تُحفظ المحاولات والمساعدة السابقة لكل قرار، ولا تُصفّر لإظهار نتيجة أفضل.
7. داخل المشروع تحدد الحقول الناقصة الاحتياج. يتغير التوجيه بحسب المرحلة وفحوصها وعدد مرات المراجعة. خلو قائمة النواقص يخفض الدعم، ولا يثبت جودة العمل.

المرشد ليس محادثة مولّدة. الشرح والبدائل والتلميحات والأمثلة مكتوبة مسبقًا، ويختارها محرك قواعد محلي.

## التصدير

- **PDF:** تُركب أقسام مستقلة، وتُوزع على صفحات A4، ثم تُرسم كل صفحة محليًا لتثبيت اتصال الحروف العربية واتجاهها. تجمعها html2pdf.js / jsPDF في ملف فعلي. تُعالج الصور والرسوم محليًا.
- **حد PDF:** النص داخل PDF مرسوم كصورة، ولذلك ليس نصًا قابلًا للبحث أو التحديد. احتفظ بملف JSON للتحرير، وبملفات HTML لإمكانية الوصول. تستهدف الأداة سلامة شكل العربية دون ادعاء مستند PDF متاح لقارئات الشاشة.
- **PNG:** ملصق بعرض 2000 بكسل. إذا تجاوزت مساحة الملصق حدود الذاكرة المحددة، تظهر رسالة تطلب اختصاره أو استخدام PDF متعدد الصفحات.
- **الطباعة:** افتح «طباعة A4»، ثم اختر الطابعة أو الحفظ PDF من حوار المتصفح. تفعيل طباعة الخلفيات يحافظ على ألوان القالب.
- تنزيل الملفات داخل iframe يتطلب السماح بالتنزيل من المنصة المضيفة. قيود المنصة لا يمكن تجاوزها من التطبيق.

## الخصوصية والتحقق

حالة المستخدم محفوظة في `Lab.state` داخل الذاكرة فقط؛ لا cookies ولا localStorage ولا sessionStorage ولا IndexedDB ولا Service Worker. لا طلبات fetch ولا خدمات خلفية ولا تحليلات استخدام. الروابط الخارجية لا تفتح إلا عند اختيار المستخدم، في تبويب جديد مع `noreferrer`.

قيمة JSON المستوردة تُفحص قبل الاستبدال: تنسيق وإصدار وحقول وأنواع وأطوال وحدود ومُعرّفات، ورفض مفاتيح تغيير prototype والروابط التنفيذية في العرض. تُعاد حساب صحة المحاولات من بيانات الأسئلة، وتُفحص المراحل المكتملة. مدخلات المستخدم تعرض كنص escaped. ألوان القالب محصورة بصيغة hex، ولا تُدرج HTML من المستخدم.

الصور المقبولة PNG وJPEG وWebP حتى 5 ميجابايت للصورة، وتُعاد رسمها محليًا إلى JPEG بحافة قصوى 1600 بكسل قبل التخزين في الجلسة. هذا يقلل الحجم ويزيل بيانات الصورة الإضافية. لا يُقبل SVG. ميزانية الصور بعد المعالجة 12 ميجابايت للمشروع. الحد الأقصى 30 عنصرًا في كل قائمة و18 ميجابايت لملف JSON المحفوظ أو المستورد؛ إذا كبر المشروع وزّعه على ملفات أو قلل الصور.

## تضمين الأداة في منصة تعليمية

ارفع المجلد كاملًا مع المحافظة على المسارات، مثل:

```html
<iframe
  src="/tools/geography-lab/index.html"
  title="مختبر الجغرافيا الذكي"
  lang="ar"
  dir="rtl"
  style="width:100%;height:900px;border:0;border-radius:12px"
  loading="lazy">
</iframe>
```

إذا كانت المنصة تشترط iframe مع sandbox، يوصى باستضافة الأداة على نطاق فرعي منفصل، والسماح بالقدرات المطلوبة:

```html
<iframe
  src="https://tools.example.edu/geography-lab/index.html"
  title="مختبر الجغرافيا الذكي"
  style="width:100%;height:900px;border:0"
  sandbox="allow-scripts allow-same-origin allow-downloads allow-modals allow-popups allow-popups-to-escape-sandbox">
</iframe>
```

هذه صلاحيات تنفيذ محلي، تنزيل، طباعة، وفتح روابط المصادر. إن لم تسمح المنصة بها، افتح الأداة في تبويب مستقل. لا يتطلب التطبيق التواصل مع الصفحة المضيفة أو مشاركة بياناتها. لا تضف ترويسات `X-Frame-Options: DENY` أو سياسة `frame-ancestors` تمنع المنصة المطلوبة. إعداد هذه الترويسات مسؤولية الاستضافة.

## الهيكل البرمجي

```text
index.html
assets/
  css/style.css             التنسيق، التجاوب، RTL والطباعة
  fonts/                    خط Tajawal وترخيصه
  vendor/                   نسخ محلية مثبتة من المكتبات
  js/
    modules-data.js         الموديولات والمحتوى والأنشطة والروبرك
    activities.js           الأنشطة، الإجابات، المراجعة والتفاعل
    smart-support.js        محرك الدعم المشترك ومستوياته
    assessment.js           المؤشرات وأدلة الممارسة والتوصيات
    project-builder.js      المراحل السبع ومحرر المنتج والرسم
    dashboard.js            لوحة الأداء وجداولها ومخططها
    export.js               التصدير وفحص JSON والصور
    app.js                  الحالة والتنقل والواجهة وخطة التدريس
README.md
USER-GUIDE.html
TEST-RESULTS.md
REQUIREMENTS.md
THIRD-PARTY-NOTICES.md
tests/                      اختبارات تطوير اختيارية
```

تُحمّل ملفات JavaScript كـ classic scripts بترتيب `defer`، وتشارك مساحة الاسم `Lab` حتى تعمل من `file://` دون ES-module server. الفصل بين البيانات والمحرك والتقويم والعرض واضح، مع اعتماد العرض على حالة واحدة في الذاكرة.

## الاختبارات وحدود التحقق

راجع `TEST-RESULTS.md` للتفاصيل. نجحت الاختبارات الوظيفية الآلية الإحدى والعشرون في Node + jsdom، مع فحص syntax لكل ملفات JavaScript والتحقق من الأصول المحلية. لا يُستخدم Node في تشغيل التطبيق؛ هو أداة تحقق للمطور فقط.

**لم تتوفر أداة متصفح فعلي في بيئة التسليم.** لذلك لم يُجر فحص بصري على الهاتف أو الكمبيوتر، ولم تُفتح ملفات PDF وPNG التي ينشئها متصفح المستخدم للتحقق من العرض النهائي. كود التصدير والمكتبات موجودان، وفُحص بناء محتوى التقارير، لكن الاختبار الآلي لا يدّعي اختبار الرسم والتنزيل والطباعة أو سلامة توزيع كل منتج ممكن على الصفحات. توجد قائمة تحقق يدوية في تقرير الاختبارات.

لتشغيل اختبارات التطوير اختياريًا (Node 20+):

```sh
cd tests
npm install
npm test
```

هذه الخطوة تحتاج الإنترنت لتنزيل jsdom عند الإعداد الأول فقط، ولا يلزم تنفيذها لاستخدام التطبيق.

## المحتوى العلمي وحدود الاستخدام

السيناريوهات تربوية مبسطة تستلهم دجلة والفرات والتصحر والمناخ والسكان والموارد. لا تحتوي بيانات إحصائية جغرافية مزعومة، ولا تدّعي مطابقة تفصيلية لمنهج عراقي معين. على المعلم مراجعة المحتوى وفق صفه ومنهجه ومصادره، ومراجعة دقة معلومات المشروع.

لم يُنشر التطبيق على خادم ولم تُنشأ حسابات أو قواعد بيانات؛ التسليم هو حزمة قابلة للتشغيل المحلي أو الرفع إلى استضافة ثابتة.
